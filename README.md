# Huzaifa Aziz — minimal portfolio

A static, responsive portfolio. No installation or build step is required.

## Upload to GitHub Pages

1. Extract this ZIP on your computer.
2. Open your `huzaifaaziz90.github.io` repository on GitHub.
3. Upload the extracted files directly into the repository root. `index.html` should be at the top level, not inside another folder. Replace the existing `index.html` and `resume-print.html`, and include `styles.css` and `assets/`.
4. Commit the changes. If Pages is already configured for this branch and root directory, it will use the updated files. Otherwise, choose that branch and `/ (root)` under Settings → Pages.

The old `_ds/` folder is no longer used and may be removed. Keep any existing custom-domain `CNAME` file or repository configuration you use.

## Files

- `index.html`: portfolio content and links.
- `styles.css`: layout, responsive styles and typography.
- `resume-print.html`: printable résumé; use your browser's Print → Save as PDF.
- `assets/`: original portrait and downloadable contact card.
- `.nojekyll`: static GitHub Pages marker.

Open `index.html` in a browser to preview locally. All content and navigation work without JavaScript. External project and profile links require internet access.
