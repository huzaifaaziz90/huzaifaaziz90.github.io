# Huzaifa Aziz — product portfolio

## Upload to GitHub Pages

Extract the ZIP and upload its contents directly into the root of your `huzaifaaziz90.github.io` repository. Replace index.html, styles.css, script.js, resume-print.html and the included assets. Commit the changes. No build, npm installation or framework setup is needed.

Keep any existing CNAME file or deployment configuration. If Pages is not already configured, select the publishing branch and `/ (root)` in Settings → Pages. The old `_ds` design directory is unused and may be removed.

## Design

Static HTML/CSS adaptation of shadcn preset `b1uI38r44`, resolved from the official init endpoint: Rhea, Mist neutral palette, cyan primary, Inter and a 0.625rem corner radius. Exact resolved tokens are in design-preset.json. This package uses the preset’s visual settings without a React runtime. Inter loads from Google Fonts with a system-font fallback.

## Edit and preview

- index.html: main portfolio content.
- styles.css: preset tokens and responsive layout.
- script.js: optional invite-code copy button (secure contexts only).
- resume-print.html: printable product-focused résumé.

Open index.html locally to review. Core content, links and expandable product details work without JavaScript. The invite code stays selectable if clipboard access is unavailable. Use your browser’s Print → Save as PDF on the résumé page.
